A one-line entry for the make.fun "The 3AM Fridge Text" bounty. At
3am the smart fridge has had enough: it only gets opened when its
owner is sad, so the ice cream stays hidden until mum gets a call.

> It's 3am. You only open me when you're sad, so I've hidden the ice cream until you call your mother.

## Run

```sh
python3 main.py
```

The script writes the line above to `entry.txt` in the output
directory (from `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`).

## Files

- `main.py` — the entry script; the text lives in `ENTRY` and is
  written out unchanged.
